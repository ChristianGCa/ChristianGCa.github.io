01 / Projeto pessoal · Em produção

Pure MD

Editor Markdown que roda inteiro no navegador, com prévia em tempo real, GitHub Flavored Markdown, destaque de sintaxe e exportação para .md. Não tem backend, conta nem analytics.

  • HTML embutido não é executado, e links com protocolos perigosos são bloqueados
  • Imagens externas só carregam depois de um clique do usuário
  • O build roda os testes (Vitest e React Testing Library) antes de gerar os arquivos

02 / Estágio · Mérito Engenharia de Software

Desk2Agile

Middleware em Spring Boot que integra o GLPI, onde os chamados são abertos, ao Taiga, onde a equipe organiza o desenvolvimento. Substituiu a criação manual de issues e o repasse do andamento a quem abriu o chamado.

  • Cria a issue no projeto certo do Taiga conforme a entidade e a categoria do chamado
  • Devolve ao GLPI o status da issue, visível para quem abriu o chamado
  • Webhooks autenticados por token Bearer e assinatura HMAC-SHA1
  • Roda em Docker, com healthcheck pelo Spring Boot Actuator
  • Java 21
  • Spring Boot
  • Docker
  • Webhooks
