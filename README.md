# Portfólio de Christian Gabriel Candeloni

Site estático em HTML e CSS, pronto para publicação pelo GitHub Pages.

## Visualizar localmente

Abra `index.html` no navegador ou execute `python3 -m http.server 8000` na raiz do repositório e acesse `http://localhost:8000`.

## Publicar

Envie os arquivos para a branch de publicação do repositório `ChristianGCa.github.io`. Nas configurações do GitHub Pages, use a raiz da branch como origem. O endereço esperado é `https://christiangca.github.io/`.

Os textos de projetos foram conferidos nos respectivos READMEs públicos. Ao atualizar o portfólio, revise também os links e a formação exibida em `index.html`.
